Amazon Connect + ElevenLabs

Guías de integración para contact centers con personalización de voz en ElevenLabs

A continuación se detallan dos enfoques para integrar voces de ElevenLabs en Amazon Connect. RAG simple con Lex o un agente conversacional completo con herramientas y base de conocimiento.

Escenario 1

ElevenLabs TTS + Lex con Bedrock RAG

Utilizando ElevenLabs y Amazon Lex con Bedrock Knowledge Base para responder preguntas. El flujo es un ciclo directo donde Lex maneja la conversación de forma nativa. Es ideal para preguntas frecuentes y soporte de primer nivel.

Amazon Connect ElevenLabs TTS Amazon Lex V2 Amazon Bedrock

ElevenLabs TTS + Agente Conversacional ElevenLabs

Un agente de ElevenLabs maneja la lógica conversacional a través de un WebSocket con Lambda. Soporta herramientas (consultar pedidos, crear tickets), base de conocimiento propia y manejo de contexto avanzado. Para conversaciones complejas con acciones.
